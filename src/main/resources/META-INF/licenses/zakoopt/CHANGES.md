# Встроенный ZakoOpt для Vela / Minecraft 26.2

## Оптимизация 3.0 — 20 октября 2026

Поиск PreparedTextCache использует временный ключ под существующей блокировкой,
без выделения нового ключа при попадании. Ключ не сохраняется в карте, ссылки
очищаются после поиска. Неизменяемые ключи создаются при сохранении результата.
Сравнение float согласовано с хешированием, включая signed zero и NaN.
Лимит LRU, сброс ресурсов и исключение анимированного текста сохранены.

## Перенос 1.1.6 — 18 октября 2026

Исходники 1.1.6 (3ako/ZakoOpt, b56c5e8) перенесены поверх адаптации 1.0.3.
Реестр Feature подключён к существующим профилям Vela; новые параметры используют
исходные значения по умолчанию. Отдельные экраны и проверка обновлений ZakoOpt не включены.
Добавлены переводы параметров, раздел памяти, обработчики и шейдеры масштаба рендера.
Сохранены адаптации HUD Vela, ограниченного пула workers и native-страниц.
Удалены неподходящие для 26.2 варианты обработчиков; диагностические GPU-таймеры
используют состояние F3. Пул поз ограничен 8192 элементами и сбрасывается каждый кадр;
буферы масштаба освобождаются при отключении и смене мира.
Перенос ещё не прошёл игровую проверку и не является подтверждением прироста FPS.

Дополнения интеграции 18 октября: единый Feature-реестр для старых getters,
отложенный сброс после смены профиля, аварийные блокировки специализированных Features,
освобождение GPU queries и occlusion-ресурсов, защита от подмены основного HUD target,
boxed-кэш света частиц с проверкой позиции. GuardWeaver подключён после проверки
генерируемого байткода; исходные исключения для горячих hooks и WrapOperation сохранены.

## Основа 1.0.3

Автор исходного ZakoOpt: Zako, https://t.me/StarikZako . LGPL-3.0-only.
Оригинальные NOTICE, COPYING и COPYING.LESSER сохранены рядом с этим файлом.

Использованы исходные слои common, 1.21.8+, sodium-0.8, 1.21.9+, 1.21.11+, 26.x и 26.2.
Пакет zako.opt перенесён в dev.sqwat.vela.zako; независимые настройки/экраны заменены
модулем Utilities → ZakoOptimization и существующим хранилищем профилей Vela.
Значения переключателей и расстояний по умолчанию соответствуют Values оригинала.
Поддерживаемые настройки определяются наличием соответствующего hook для 26.2.
Модуль по умолчанию выключен; отдельный внешний ZakoOpt отключает встроенную интеграцию.

Перенесены доступные в 26.2 оптимизации моделей, частиц, предметов, спавнеров, текста,
блочных сущностей, GUI/HUD, а также применимые OpenGL/Sodium/Lunar hooks.
Sodium, Iris и ImmediatelyFast не упакованы в Vela и не обязательны для базового пути.
Их интеграции включаются только при наличии соответствующей внешней библиотеки.
Нативный Vulkan Minecraft 26.2 использует backend-independent пути; OpenGL-only методы
не применяются к Vulkan-текстурам. VulkanMod имеет отдельные ограничения совместимости.

Изменения Vela:
- ограниченный ленивый пул работников, барьер завершения задач без busy-spin;
- пакеты по восемь моделей; переиспользование временных векторов отдельно по потокам;
- сокращение количества и ёмкости native-страниц после снижения рабочего набора;
- освобождение workers/native buffers/атласов/кэшей при отключении, смене мира и reload;
- живое обновление HUD Vela, Motion Blur и стекла вне кэшируемого ванильного HUD;
- композиция кэша и живого HUD в общей GUI-пачке с native strata;
- принудительное обновление outline target после смены GPU-текстур;
- кэш текстов с неизменяемыми ключами, учётом Font и без повторного оборачивания;
- кэш освещения частиц учитывает позицию; временная физика восстанавливается в finally;
- OpenGL texture-buffer cache ограничен render pass и не записывается при отключении;
- исходные updater, debug overlay и отдельные ModMenu/Sodium экраны не включены.
- ранняя проверка расстояния блок-сущностей использует уже выбранный renderer без CallbackInfoReturnable на каждом вызове.

В исходной ветке 26.2 отсутствуют ImmediateRing/старые BufferSource hooks; невыполняемые
настройки скрыты, а управление submission fences остаётся у Minecraft.
Порт не добавляет графический backend, FSR или генерацию кадров.
Игровой прирост FPS и совместимость произвольных сторонних модов не подтверждены замером.

Изменённые исходники включены в META-INF/zakoopt-source клиентского JAR, полный sources JAR
и архив проекта vela-client-source.zip. Инструкции пересборки: SOURCE_BUILD.md.

Изменение раскладки (2026-10-26): подпакеты feature.* и bench/cpu перенесены в feature и корневой пакет zako; подпакеты mixin сохранены.
