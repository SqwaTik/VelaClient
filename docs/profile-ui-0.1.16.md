# Проверка профиля и интерфейса — 0.1.16

Профиль: `%APPDATA%/.vela/debug/vela-perf/vela-1789964685157.jfr`. Сводка: 29 977 кадров, среднее 1,69 мс, p95 3,10 мс, p99 4,28 мс, максимум 72,11 мс, восемь кадров дольше 16,67 мс. Семь из этих восьми интервалов пересекаются с GC-паузами (22,3–28,4 мс). Первый длинный интервал не пересекается с GC; в записи есть работа инициализации JFR, поэтому его нельзя автоматически приписать игре. Вес allocation samples является оценкой, а не точным подсчётом байтов.

В игровых стеках видна подготовка текста табличек. Добавлен пропуск действительно пустых текстовых submissions без фона до выделения матрицы и записи текста. Строки с пробелами, видимый текст и фон не пропускаются. Это узкая оптимизация, а не доказательство устранения всех GC-пауз. Повторный игровой замер после изменения необходим.

Исправления интерфейса:

- Компактное уведомление РП не появляется до создания игрока и выхода из LevelLoadingScreen.
- Кнопка Drag Mode заканчивает расширение за 200 мс без длительного добора последних пикселей.
- СКМ-меню использует ширину 108 и масштаб 1, как ПКМ-меню. Высота соответствует одной настройке.
- Прокрутка аккаунтов сохраняет скорость при новых событиях колеса, использует дробное смещение и завершает движение точно.
- Подсветка выбранного аккаунта интерполируется; при возвращении из входа панель раскрывается плавно.
- Microsoft-экран использует рассчитанную анимацию; после успешного добавления есть состояние подтверждения. Успех показывается по времени видимой анимации, а не по времени фонового callback.

Проверка: Gradle build, 184 теста без ошибок, включая тайминг переходов, готовность уведомления РП, пустые строки и сигнатуру точки внедрения Minecraft 26.2. Полная визуальная проверка в игре не выполнена. Авторизация и хранение токенов не менялись.
