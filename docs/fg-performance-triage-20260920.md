## Контрольный запуск

`gradlew.bat runClient --offline --console=plain --args='--graphicsBackend VULKAN'`

Без `fgDeviceProbe`, `fgSurfaceProbe`, `--vulkanValidation` и переменных `VK_*`. Для сравнения пользователь должен выбрать ту же сцену и настройки, держать окно активным и дождаться завершения загрузки чанков. Вход на сервер автоматически не выполняется.
