# Превью шалкера и Crosshair

## Поведение

- Shulker Preview перенесён в утилиты. Убирается только стандартный текстовый перечень содержимого: название и прочие свойства предмета сохраняются.
- Наведение на шалкер, затем удержание левого или правого Ctrl закрепляет показанную сетку. Наведение на её предметы вызывает стандартные подсказки Minecraft, включая зачарования. Отпускание Ctrl, смена экрана или мира снимает фиксацию. Клики внутри закреплённой панели не передаются инвентарю под ней.
- Превью показывает только уже полученные клиентом данные контейнера. Инвентарь не изменяется.
- Уведомление: «Создана метка», ниже отдельной строкой название.
- Новый визуал Crosshair опирается на Crosshair из локального KimikoSRC: крестик/круг, размер, толщина, отступ, расширение по перезарядке атаки, точка, цвет клиента и реакция на цель. Пиксельный редактор и инерция из Kimiko в этот модуль не переносились. По умолчанию модуль выключен.
- Заменяется только первый спрайт в штатном отображении прицела; штатные проверки камеры, наблюдателя, отладочного прицела и индикатор атаки сохраняются.
