# Доработка интерфейса — 14 октября 2026

## Требования

- Аккаунты: соответствие Prompt Submission.zip, размеры, читаемые шрифты, значки Microsoft и метаданных, фон/анимация меню, наведение, выход. Меню не выбирает профиль; двойной клик входит; вкладка Microsoft не открывает браузер автоматически.
- Общие элементы: более выразительные цвета, спокойная анимация закрытия, осмысленные значки поднастроек.
- Метки: значок рядом с именем в уведомлении, цвет смерти соответствует акценту, описание переключателя меток смерти.
- Macros / Interval Commands: компактный редактор со значками.
- Pinger: центральный Notifications, значки сердца/настроек порога, опциональное красное предупреждение по краям экрана.
- Команды: локальные `.gps x [y] z`, `.cfg load/save/remove <имя>`, `.cfg dir`; подсказки при ошибках, кнопка папки в GUI.
- Конфиги: расширение `.vela`, совместимость старых файлов и кодов, более короткий переносимый код без сетевого хранилища.
- РП: изучить распределение загрузки между кадрами и уменьшить блокировки без повреждения ресурсов.
- Оптимизация FPS вне текущего объёма. Игру не запускать и ПК не управлять.

## Проверенные этапы

- Удалён автоматический старт Microsoft при открытии вкладки; начало входа требует кнопки.
- Меню строки отделено от выбора профиля; восстановлен двойной клик для входа.
- VELA3 исключает значения по умолчанию из переносимого JSON и использует максимальное DEFLATE-сжатие; читает VELA1/VELA2. Проверка ConfigShareTest и AccountLayoutTest прошла.

## Реализовано и проверено сборкой

- Аккаунты: увеличены подписи, центрированы группы Microsoft/Offline, добавлены значки метаданных и Microsoft; уменьшено меню строки, исправлено разделение выбора/меню и двойной клик. Появление профиля, меню и окна входа использует существующий механизм анимации. Живая авторизация и плавность в игре не проверялись.
- Общие цвета и кнопка закрытия обновлены, значки настроек стали смысловыми. Пользовательский акцент сохраняется.
- Метки смерти используют текущий акцент; добавлено описание, значок возле имени созданной метки и корректный отступ для длинного имени.
- Редакторы Macros / Interval Commands компактнее, со значками и адаптацией полей к небольшой высоте окна.
- Pinger выводит предупреждение в центральный Notifications; здоровье отмечено сердцем, порог брони — настройками. Добавлено отключаемое красное предупреждение по краям экрана.
- Локальные команды: `.gps x z`, `.gps x y z`, `.cfg load имя`, `.cfg save имя`, `.cfg remove имя`, `.cfg dir`. Ошибки выводят подсказку; распознанные команды не отправляются серверу. Удаление конфига переносит его в архив.
- Кнопка папки добавлена в конфиги. Профили сохраняются как `.vela`; старые `.json` переносятся без перезаписи новых. При совпадении имён старый файл сохраняется в `profiles/legacy-backup`, чтобы не восстановиться неожиданно после удаления нового.
- Расположение, масштаб HUD и их исходные значения объединены в `hud.vela`. Четыре прежних файла переносятся в `legacy-hud-backup` только после успешной записи нового файла.
- Переносимые коды VELA3 исключают значения по умолчанию и сжимаются DEFLATE. VELA1/VELA2 читаются; размер распаковки ограничен. Короткий сетевой идентификатор не используется.

## Ресурс-паки

Изучены RemoveReloadingScreen и Repacked, а реализация сверена с исходниками TextureManager / ReloadableTexture установленной версии Minecraft 26.2. Декодирование и подготовительный барьер сохранены; применение отдельных текстур распределено между кадрами: максимум 8 задач и ориентировочный бюджет 1,5 мс. Завершение reload происходит после последней задачи. Начальная загрузка игры не заменяется.

Бюджет не прерывает одну тяжёлую загрузку. Атласы, модели и другие слушатели применения ресурсов остаются отдельными источниками пауз. Эффект на конкретном серверном РП и совместимость с другими модами требуют игрового замера; обещания отсутствия зависаний нет.
