# Crosshair: динамика и Hit Color

Сверены локальные исходники Kimiko Crosshair и HitColor (CC0), а также фактические методы Minecraft 26.2.

- Круг: постоянный радиус, сокращение/возвращение дуги по интерполированной анимации взмаха, тёмная подложка, градиент и инерция при поворотах. Старое увеличение радиуса по кулдауну удалено.
- «Динамика» отключает смещение и анимацию атаки; цветовая реакция остаётся самостоятельной настройкой. У крестика динамика управляет расширением лучей.
- Реакция использует EntityHitResult штатного наведения. Цвет меняется плавно; для темы, близкой к розовому цвету реакции, выбирается светлая подсветка. Прежний crosshairPickEntity в ванильном Minecraft заполняется тем же результатом: неправильный источник цели не доказан, дальность взаимодействия не изменена.
- Состояние инерции очищается при выключении, смене мира/экрана/перспективы. Переход угла через 180 градусов не бросает прицел в сторону.
- Круг отправляется одним GUI-элементом без текстур и массивов вершин на каждый кадр; геометрия ограничена 64 сегментами на слой. Реальный выигрыш FPS не измерялся.
- Добавлен Hit Color: цвет модели живого игрока при штатном получении урона, включая локального FakePlayer. Цвет клиента или пользовательский. Мобы и анимация смерти не затрагиваются. Модуль по умолчанию выключен.

373 теста, 0 ошибок; test/build/sourceBundle успешны. Проверены настройки после сохранения, состояния динамики, углы, диапазон дуги, границы геометрии и дескрипторы перехватов.
