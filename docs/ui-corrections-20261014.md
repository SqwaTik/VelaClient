# Исправления по игровым скриншотам

## Поведение

- Прежняя загрузка РП восстановлена: удалены очередь отдельных текстур и два её перехвата. Начальная загрузка, обычные обработчики ресурсов и прежний компактный индикатор остаются.
- Рамки `account_modal` и `account_hero` теперь помещаются целиком внутри PNG: раньше линия проходила по границе холста и обрезалась справа/снизу.
- Убраны вертикальные смещения профиля, контекстного меню и окна добавления аккаунта. Наведения и плавный скролл сохранены.
- Заголовок Vela Manager, центрированная группа логотипа/названия в широком окне, кнопки Microsoft/Offline без плюсов, зелёная точка справа, значок возле типа аккаунта, серая подсказка клавиш.
- Поиск без рамки; совпадения имени выделяет существующий SearchText.
- Успешный вход не возвращает экран немедленно. Компактный статус показывает переход индикатора в галочку и остаётся примерно 1,2 секунды после успеха. Статус появляется только по реальному результату IAS. Ошибка/пароль сохраняют полноценные формы.
- В уведомлении о метке верхний значок — галочка создания, нижний — значок самой метки.
- Точка в чате открывает штатный список подсказок Minecraft с `.cfg` и `.gps`; доступны подкоманды и имена конфигов. Tab/стрелки/мышь обрабатывает штатный список. Ответы оформлены `Vela Visual -> …` с клиентским акцентом.
- Пинг: стандартный запрос Minecraft не чаще раза в секунду, один ожидаемый ответ, таймаут 5 секунд; без свежего ответа используется серверное значение. При отключённом watermark/ping новые запросы не отправляются.
- Pinger: значок здоровья/брони перед значением; мягкое появление/затухание красных краёв и медленная пульсация, отключённая в режиме уменьшенного движения.

## Проверка и границы

Проверки геометрии/PNG, подсказок и плавного предупреждения выполняются вне игры. Совпадение новых перехватов с установленным Minecraft проверяется по байткоду. Авторизация, сетевой ответ сервера, живой рендер и время загрузки РП требуют игрового подтверждения. Игра и управление ПК не запускаются.
