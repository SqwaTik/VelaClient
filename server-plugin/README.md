# Vela Rules

Плагин для Paper и Spigot: в `config.yml` отмечаешь, какие функции клиента [Vela](../README.md) отключить у игроков на твоём сервере.

У игрока с Vela эти функции выключаются и скрываются, пока он на сервере, и он видит уведомление, что именно отключил сервер. Когда игрок выходит, функции возвращаются. Игроки без Vela ничего не получают.

Плагин нужен только тогда, когда хочется держать список в конфиге. Без него то же самое делается одной строкой: `/tellraw @a "velaclient:disable freelook hitboxes"` (подробности в [README Vela](../README.md#для-владельцев-серверов)).

## Установка

1. Собери `vela-rules-<версия>.jar` (см. ниже). Начиная со следующего релиза Vela он будет лежать и в [Releases](https://github.com/SqwaTik/VelaClient/releases).
2. Положи jar в папку `plugins` и перезапусти сервер. Нужен Paper или Spigot 1.20.5 или новее и Java 21.
3. Открой `plugins/VelaRules/config.yml`, поставь `true` у функций, которые надо отключить.
4. Выполни `/velarules reload`.

## Конфиг

```yaml
# Отключить все функции, дающие преимущество, поверх списка ниже.
all-competitive: false

# Игроки с этим правом ничего не получают.
bypass-permission: vela.rules.bypass

functions:
  freelook: true    # отключить Freelook
  hitboxes: true    # отключить Hitboxes
  motion_blur: false
  # ... в конфиге перечислены все функции Vela с описанием
```

В `config.yml` перечислены все функции Vela по группам: дающие преимущество в PvP, HUD, визуал, утилиты. У каждой функции есть описание на русском и на английском.

## Команды и права

| Что | Зачем | По умолчанию |
|---|---|---|
| `/velarules reload` | перечитать конфиг и отправить новый список игрокам онлайн | — |
| `vela.rules.admin` | право на `/velarules` | op |
| `vela.rules.bypass` | у игрока с этим правом ничего не отключается (имя права меняется в конфиге) | никому |

После `/velarules reload` новые отключения действуют сразу. Если ты снял `true` с функции, у игроков онлайн она вернётся только после перезахода: Vela не даёт серверу включать функции обратно, только выключать.

## Как это работает

Сразу после входа Vela регистрирует канал `velaclient:disable`. Как только игрок это сделал, плагин отправляет ему в этот канал список из конфига. Формат пакета: VarInt — количество строк, затем строки (VarInt-длина и UTF-8), до 256 строк по 64 символа. Это тот же пакет, который можно отправить из своего плагина.

## Сборка

```bash
../gradlew -p server-plugin build
```

Собирать из корня репозитория, нужен JDK 21 или новее. Jar появится в `server-plugin/build/libs/`.

Тест `ServerRulesTest` в моде проверяет, что в `config.yml` перечислены все модули Vela. Поэтому если добавляешь в Vela новый модуль, добавь его и в конфиг.
