# Проверка визуалов и локального игрока — 16 октября 2026

Этот срез заменяет описание прежнего состояния в visuals-20261016.md.

- ViewModel: независимый захват руки в режиме «Обе», удалена магнитная привязка, добавлена сворачиваемая панель и усилена читаемость подсказок.
- TargetESP: режимы «Ромб», «Кружок», «Crystal», «Призраки», «Призраки 2». Используется цель Target HUD; геометрия отображается поверх брони. Отдельная настройка толщины удалена.
- Near: расширяющийся общий радиус, разделение стрелок, плавное появление, подписи без плашек. Пропуски кадров больше не сбрасывают срок появления игрока.
- DashTrail: вертикальный след высотой тела, ограниченная история.
- Стекло HUD: преломление края и три выборки RGB. Ударная волна: более широкий профиль преломления и непрерывное расширение. Производительность и визуальный результат не измерены в игре.
- FakePlayer: штатный вызов атаки игрока, штатная отдача, окно неуязвимости, броня, поглощение, базовые зачарования защиты/остроты/отдачи, локальная прочность экипировки и использование тотема. Экипировка копируется, настоящий инвентарь не изменяется. Клиентский манекен не воспроизводит произвольные серверные зачарования и правила боя; серверные эффекты, включая регенерацию, требуют дополнительной проверки.
- Ранее внесённые настройки визуалов друзей и исправление инвалидации чанков при отключении Far сохранены.

Проверка: `test build sourceBundle` завершилась успешно, 309 тестов, 0 ошибок. Тесты проверяют детерминированную логику и часть точек подключения к Minecraft 26.2. Игра не запускалась, визуальная проверка и применение mixin во время запуска не подтверждены.

Открытый прежний список: Ambience/Rain/Sky shader, Animations/SwordAnimations, KillEffect, Particles, Shaders для рук, ShulkerPreview. Эта сборка не закрывает весь список визуалов.
