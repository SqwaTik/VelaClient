# Уточнение визуалов — 16 октября 2026

## Изменения

- ViewModel: удалены прямоугольники исходных позиций. Редактор ограничивает глубину и положение опорной точки рук по текущей проекции. Свёрнутая вкладка стала компактнее и расположена выше. Её кнопка подсвечивается только при наведении; стрелка поворачивается вместе с анимацией панели. Используется общий механизм анимации с более медленным переходом формы.
- FakePlayer восстанавливает здоровье после смертельного тренировочного удара. Сохраняются реакция на удар, броня, поглощение и использование тотема.
- Обводка HUD плавно исчезает вместе с непрозрачным фоном.
- TargetESP: ромб использует PNG из предоставленного Energy. Кружок стал горизонтальным ободом, движущимся по высоте цели. Crystal состоит из вращающихся малых кристаллов со свечением. Режимы призраков не изменены.
- DashTrail: сплошная лента заменена текстурными частицами по объёму тела; использованы 21 PNG из Energy. Это адаптация механики к Minecraft 26.2, не перенос всех дополнительных настроек исходного модуля. До 192 частиц на локального игрока и видимых друзей суммарно; история сбрасывается при смене мира.
- В раскрывающийся список «Визуалы друзей» добавлены ChinaHat, DashTrail, JumpCircle. Настройки по умолчанию включены; эффекты требуют включённого соответствующего модуля. Общий предел активных ударных волн сохранён.
- Добавлен KillEffect: эффект смерти наблюдаемой цели, цвет клиента/RGB, длительность и количество искр. До трёх одновременных вспышек; при уменьшении движения остаётся только свечение.
