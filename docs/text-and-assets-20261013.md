# Текст интерфейса, таблички и размер ресурсов

## Основание

Профиль `vela-1791833482859.jfr` показывает затраты в проверках пересечения GUI-элементов, поиске фаз PNG-глифов и расчёте ширины строк табличек. Среднее время кадра этого замера — 1,93 мс, p95 — 3,37 мс, p99 — 4,54 мс; четыре паузы GC — около 34–38 мс. Сцены разных записей не являются контролируемым A/B-тестом.

## Изменения

- Одна строка собственного PNG-текста отправляется одним GUI-элементом вместо отдельного элемента на букву. Сохраняются геометрия, UV, цвет, scissor и снимок матрицы; порядок внешних GUI-элементов остаётся у Minecraft. Новых GPU-ресурсов нет.
- Фазы глифов ищутся по целочисленному codepoint и массиву из четырёх вариантов, без упаковки составного Long на каждую букву.
- Ширина неизменяемых строк SignText кэшируется по идентичности. Лимит — 2048 строк; смена шрифта, перезагрузка шрифтов и смена мира очищают кэш. Произвольные строки чата не кэшируются этим механизмом.
- 57 белых шрифтовых масок переведены в стандартный индексированный PNG: индекс хранит один из 256 уровней прозрачности, RGB палитры остаётся белым. Исходные 20 237 990 байт стали 13 801 387 байт: экономия 6 436 603 байта (31,8%). Размеры изображений, сглаживание и все RGBA-пиксели сохраняются. Три старых атласа другого представления не изменены.

Инструмент `tools/CompactFontPng.java` по умолчанию делает пробный прогон. `--apply` заменяет только меньшие файлы после полного сравнения декодированных пикселей. Исходные изображения сохранены вне проекта в `work/outputs/font-png-originals-20261012`.

## Границы результата

PNG декодируется существующим NativeImage в RGBA. Это уменьшение файлов, а не четырёхкратное сокращение видеопамяти. Одноканальные GPU-текстуры потребовали бы отдельного пути загрузки и шейдера; они в этот этап не включены. Собственного формата и дополнительных библиотек нет.

Тесты сравнивают вершины старого и нового текста при 200 преобразованиях, проверяют отсечение, все размеры/фазы шрифтов, идентичность пикселей при декодировании Minecraft, ограничение и очистку кэша ширины и точную сигнатуру mixin. Без запуска игры не проверены итоговый внешний вид на Vulkan, совместимость mixin со всеми сторонними модами и изменение FPS в сцене с серверным изображением.

## Источники подхода

- [MoreCulling: Item Frame Culling](https://github.com/fxmorin/MoreCulling/wiki/Item-Frame-Culling): уменьшает работу для скрытых рамок/карт, но не устраняет стоимость изображения, на которое смотрит игрок.
- [ImmediatelyFast: обсуждение современного GUI batching](https://github.com/RaphiMC/ImmediatelyFast/issues/382): пакетирование следует согласовывать с существующим GUI-путём Minecraft.
- [ImmediatelyFast: регрессия HUD batching](https://github.com/RaphiMC/ImmediatelyFast/issues/200): глобальное вмешательство в порядок GUI может нарушать отображение. Здесь объединяются только глифы одной собственной строки.

Контракты NativeImage, GuiRenderState, BlitRenderState, SignText и AbstractSignRenderer проверены по разрешённым исходникам Minecraft 26.2 из Loom.
