# Shaders / Animations — рабочий план

## Текущий проход: облегчение эффектов, 19 октября

Чёрная дыра переписана как аналитический диск/горизонт/ореол с одной выборкой заранее загруженного шума. Удалены 200-шаговая трассировка и тяжёлый полноэкранный HDR-композит; bloom ограничен тремя уровнями. Это другая визуальная модель, её сходство и производительность ещё требуют проверки в игре. Шум создаётся один раз на GPU-текстуру; отдельный PNG пока не добавлен.

Стекло рук заменено локальным преломлением по границе альфа-маски без вертикального переворота сцены и simplex-noise. Голограмма использует пять выборок маски вместо многократного расширения цвета/глубины. Корректность самого захвата рук в проблемной сцене пока не подтверждена; считать полноэкранное искажение устранённым рано.

По latest.log подтверждён сбой мокрых поверхностей из-за несовпадения RGBA16_FLOAT-буфера и RGBA8-прохода. Формат WET исправлен, регрессионный тест проверяет реальные WET/WET_RESOLVE pipeline. Сборка и офлайн-компиляция всех GLSL прошли. Запущенный клиент всё ещё использует предыдущий JAR; установленный файл не заменён во время работы игры. Остальные старые разделы ниже отражают историю реализации, не итоговую визуальную проверку.

Запрошено: единый Shaders со всеми готовыми шейдерами Kimiko, включая руки, небо, туман, мокрые поверхности и редактор GLSL. Animations для интерфейса; независимый цвет неба и цвет клиента в Ambience.

Источник режимов: локальные Kimiko ShaderHands, Ambience, BetterMinecraft (CC0). Energy Animations прочитан для уточнения назначения, код оттуда не переносится.

Порядок: (1) Ambience: skyColor, (2) Animations: чат/Tab/контейнеры/хотбар, (3) единый жизненный цикл shader-проходов, (4) готовые эффекты рук/неба/тумана/мокрых поверхностей, (5) локальный редактор GLSL с ограничением размера, диагностикой и возвратом к последнему рабочему варианту.

Не считать Shaders готовым по наличию настроек: каждый режим должен иметь подключённый рендер, освобождение ресурсов и проверку ошибок/отключения. Новые функции по умолчанию выключены. Игра не запускается без отдельного разрешения.

## Первый этап

Уточнение анимаций: открытие строки ввода чата теперь имеет отдельный переход 170 мс с кривой Back и смещением 8 пикселей при высоте окна 1080. Фактический EditBox перемещается вместе с фоном, сохраняя совпадение клика и поля. Tab использует равномерный масштаб обеих осей, Back-переход 300 мс и сокращённую длительность при смене направления, по PlayerTabOverlayMixin из Kimiko. Исходные параметры проверены в локальных исходниках (CC0); игровая визуальная проверка не выполнялась.

Реализованы цвет небосвода в Ambience (cloudColor не меняется), новые сообщения чата, раскрытие/сворачивание Tab, открытие контейнеров и движение выделения хотбара в Animations. Положение контейнера меняется через штатный topPos, совпадает с кликами, учитывает окончательный init подкласса. Неактивная анимация не переписывает положение. Анимация сообщений выключена при открытом чате/прокрутке, чтобы не смещать кликабельные ссылки.

Проверены компиляция, дескрипторы методов MC 26.2 и детерминированные переходы. Игровой проверки пока нет.

## Шейдерный туман

В Shaders подключён первый реальный проход — высотный туман Kimiko: плотность, высота, прижатие к земле, дымка неба, цвет клиента/свой цвет. Модуль по умолчанию выключен. Рендер выполняется после LevelRenderer.render, до очистки глубины и рук, не затрагивает HUD. Под водой/в лаве пропускается. Снимки цвета/глубины и uniform-буфер переиспользуются и освобождаются при отключении, смене мира, размере окна и закрытии рендера; ошибка компиляции отключает проход до повторного включения/смены мира.

Проверено по байткоду 26.2: RenderPass.draw(vertexCount,instanceCount,firstVertex,firstInstance), то есть draw(6,1,0,0). Проекция использует обратную глубину (небо — 0); диапазон NDC зависит от DeviceInfo.isZZeroToOne. Захватывается фактическая проекция после bob/hurt/portal-преобразований, а не исходная CameraRenderState.projectionMatrix.

## Состояние 19 октября

Исправление по игровому latest.log (06:44:31/06:44:43): небо и руки отключались при clearColorTexture/clearColorAndDepthTextures, потому что целевые текстуры не имели USAGE_COPY_DST. Флаг добавлен также к глубине рук и истории пламени. Регрессионный тест вызывает настоящий CommandEncoder с заглушкой GPU-backend: старые флаги дают исходное исключение, исправленные принимаются для очистки цвета и глубины. Это проверка контракта API, не визуальный запуск.

Оптимизация: среднее качество неба и отражений использует половинное разрешение по каждой оси. Для отражений сохраняется только изменение освещения в RGBA16_FLOAT; полноразмерный кадр собирается с четырьмя соседями и отсечением по относительной глубине. Детали исходной сцены не масштабируются. Низкое качество — треть разрешения, высокое — полное (чёрная дыра ограничена половинным). Неиспользуемые три уровня bloom у обычного неба больше не рассчитываются. Прирост FPS и качество границ требуют игрового замера.

Подключены мокрые поверхности с тремя уровнями трассировки, голограмма/стекло/пламя рук, северное сияние/звездопад/чёрная дыра и редактор GLSL неба. Руки захватываются из штатной отрисовки в отдельные цвет/глубину, временные output overrides восстанавливаются в finally. Пламя использует переиспользуемую историю в треть разрешения. Небо рисуется до геометрии; чёрная дыра использует половинное разрешение, историю и шум, bloom — шесть уменьшающихся уровней.

Редактор использует штатное многострочное поле с выделением/буфером обмена. Неприменённый черновик сохраняется при закрытии; успешный код сохраняется в конфиге. Код из конфига требует явного «Применить» в текущем сеансе. При ошибке компиляции рабочий исходник не заменяется. Текущий редактор предназначен для неба; пользовательский GLSL рук и полный набор параметров исходного ShaderHands пока не перенесены.

Проверки: компиляция Java, офлайн-компиляция GLSL, сохранение настроек и ограничение размера кода. Игровая/драйверная проверка и замеры FPS не выполнялись. Глобальная очистка pipeline cache при явном применении GLSL может вызвать однократную перекомпиляцию остальных программ; не вызывается каждый кадр.
