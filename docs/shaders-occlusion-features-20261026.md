# Шейдеры, отсечение сущностей, функции — 26 октября

## Шейдеры
- Туман: смешивание SRC_ALPHA/ONE_MINUS_SRC_ALPHA вместо копии кадра; глубина читается из основного буфера напрямую (usage 15 у RenderTarget). При одном тумане копий кадра 0 вместо 2.
- Мокрые поверхности: остаётся одна копия цвета (resolve пишет scene+знаковую дельту), копия глубины убрана, второй копии цвета для тумана нет.
- Отдельные uniform-буферы для тумана, мокрых поверхностей и уровней bloom неба.
- Северное сияние: цикл слоёв пропускается при rd.y ≤ 0.02, где все полосы точно равны нулю.
- GPU-время не измерено; JFR его не показывает.

## Отсечение сущностей за блоками (`render.entity.EntityOcclusion`)
После штатных проверок frustum и видимости секций. Лучи от камеры к центру и 8 углам бокса, препятствие — только `isSolidRender`. Бюджет 0,25 мс/кадр, кэш 150 мс (видим) / 50 мс (скрыт), сброс при смещении камеры > 0,75 блока. Новые сущности сначала видимы.
- Игроки: скрываются модель, броня, предметы, плащ, тень; ник и поводок остаются.
- Картины/рамки, голограммы (кроме TextDisplay с see_through), мобы без имени — полностью.
- Исключения: ближе 4 блоков, свечение, пассажиры/транспорт игрока, камера внутри блока, наблюдатель.
- Настройки: «Оптимизация 3.0» → «Сущности», включены по умолчанию.
- Тест `OcclusionRayTest`: совпадение с точной проверкой отрезок/воксель на >4000 сценах.
